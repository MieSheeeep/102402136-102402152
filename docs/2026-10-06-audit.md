# MVP 检查记录

检查范围：数据校验、存储事务、查询组合、发布/编辑、设置、模板转义与归属判断。当前为本地演示版本。

## 确认并修复的问题

| 问题 | 后果 | 修复及验证 |
|---|---|---|
| 我的发布保留旧的完成/类型筛选 | 新发布记录可能被隐藏，看起来像发布失败 | 发布和编辑保存成功后恢复全部类型、全部状态；控制器回归测试 |
| 默认排序更新不同步到筛选草稿 | 点击应用后设置被旧排序覆盖 | 保存默认排序时同步当前列表与草稿；控制器回归测试 |
| 多标签页用旧快照保存 | 后保存的旧页面可能覆盖另一页新增记录/收藏 | 保存前比较读取时的原始存储与当前存储；变化时阻止写入并提示刷新；存储回归测试。该检查不等于服务端事务或跨设备同步 |

## 检查结果与边界

- 57 项自动测试和 JavaScript 语法检查通过。
- 测试包含输入转义、日期校验、未知历史时间兼容、多区域持久化与搜索、完成状态、发布者归属、存储损坏保护与保存失败。
- 模板中的用户输入使用转义；发布/修改/完成/删除流程使用固定演示用户的归属校验。这不是服务端安全审计，不能由此保证没有其他安全问题。
- 当前没有真实账号或后端，浏览器拥有者可以修改本地存储中的用户与记录；不能作为真实多用户环境的权限保护。
- 紧急联系仍是明确标注的示例入口，不执行真实公告提交。
- 本轮未完成真实浏览器与手机的完整走查；此前 Edge 扩展界面持续阻挡自动操作，最新浏览器库存也没有保留 MVP 预览页。
