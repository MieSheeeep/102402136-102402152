# 校园失物招领本地 MVP Implementation Plan

> 使用 superpowers:executing-plans 在当前会话逐项实施；无需并行代理。用户已要求实现本地 MVP。

**Goal:** 在 Chrome 可直接打开的网页中完成失物信息发布、查找、详情与发布者管理闭环。

**Architecture:** 采用传统 defer 脚本，不依赖网络、构建工具或服务端。数据规则、存储、示例数据与视图控制分文件；所有写操作先保存成功，再更新界面。固定演示用户负责本人发布，其他用户数据为示例。

**Tech Stack:** HTML、CSS、JavaScript、SVG 默认图片、localStorage；Node 内置 node:test 验证纯业务逻辑。

## 文件职责

- `index.html`：桌面顶部导航、手机底部导航、主内容容器、对话框、反馈区域。
- `css/styles.css`：暖橙色与米白视觉规范、响应布局、表单和详情样式。
- `assets/default-item.svg`：所有物品共用的默认插画。
- `js/data.js`：校验、创建、搜索、编辑、状态、删除、收藏与可靠存储。
- `js/seed.js`：明确标为示例的初始记录。
- `js/views.js`：纯 HTML 渲染函数及图标、日期、文本转义。
- `js/app.js`：导航、事件、表单、对话框和写操作集成。
- `tests/data.test.cjs`：业务分支测试。
- `README.md`：运行、目录、数据限制、测试及协作建议。
- `docs/mvp-verification.md`：本轮实际验证证据。

## 本次边界

本地存储；没有后端、登录或跨设备同步；默认图片；不做上传、分享链接与实时聊天。编辑不能更改类型，完成记录不重新打开。第一版先提供地点与类型筛选、收藏和联系方式复制。
