# 多选筛选与事件时间实施计划

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 完成已确认的多选地点/分类、事件日期范围、漏斗入口与我的发布已完成筛选。

**Architecture:** 继续使用静态页面和现有本地存储。时间字段增加可选 timePrecision，兼容旧记录；筛选面板维护草稿，点击应用才改变列表。

**Tech Stack:** HTML、CSS、JavaScript、Node 内置测试。

## 确认的交互

- 外露寻物、招领、收藏和漏斗按钮，漏斗显示已启用的额外条件组数量。
- 地点与分类使用带勾的多选标签；组内取并集，组间取交集，未选代表不限。
- 时间范围：不限、今天、近3天、近7天、自定义起止日期。筛选丢失/拾取日期，首尾均包含；近3天包含今天及前2天。
- 排序仍使用发布时间，最新发布/最早发布单选。重置只重置面板草稿；点击应用才生效并收起，关闭不应用。
- 发布时间自动生成，编辑、完成与撤销不改变。事件时间支持具体时间、大致日期、时间不详；未知记录在时间不限时展示，指定日期范围时排除。
- 首页、公告和收藏展示丢失/拾取时间；详情与我的发布另外展示发布时间。
- 我的发布增加独立已完成筛选，与寻物/招领类型组合使用；收藏不受该状态筛选影响。
