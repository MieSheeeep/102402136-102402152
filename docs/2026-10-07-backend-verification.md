## 走查修正

- 进入广场、我的、详情、用户主页时重新读取后端，避免两个账号切换页面时使用旧列表。
- 公告表单字段 `id` 会覆盖浏览器表单 DOM 的 `id` 属性，导致提交没有进入处理器；改为 `itemId`，真实 Chrome 提交通过。
- Fastify Static 新版 setHeaders 接收 reply 对象，上传图片读取使用 reply.header 后重启读取测试通过。
- 收藏成功后基于最新前端状态更新收藏数组，避免不同卡片并行请求覆盖刚完成的本地结果。
- 收藏计数更新仅作用于自己的个人中心，公开用户主页的“已完成”统计不再被收藏操作修改；浏览器断言先复现失败，再验证修正。
